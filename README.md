# Oh Yes Events - Wedding Planning Companion

A beautiful, multi-step wedding planning form that helps couples plan their dream wedding. Collects all essential information, allows service selection from 90+ items, and sends the complete plan via EmailJS.

## 🌟 Features

- **4-Step Progressive Form** - Easy to fill, doesn't overwhelm users
- **Comprehensive Service Checklist** - 90+ wedding services across 8 categories
  - Stationery, Guest Stays, Transport, Gifts
  - Entertainment, Vendors, Comfort, Add-ons
- **Smart Validation** - Required fields validated before proceeding
- **Progress Tracking** - Visual progress bar for checklist completion
- **PDF Generation** - Auto-generates professional PDF summary
- **Email Integration** - Sends complete plan to your email using EmailJS
- **Responsive Design** - Works perfectly on mobile, tablet, and desktop
- **Modern UI** - Beautiful orange-themed design with smooth animations

## 📋 Form Sections

### Section 1: About You & Celebration
- Client name, phone, email
- Event type (Wedding, Engagement, Reception, etc.)
- Event date, venue, guest count
- Number of celebration days

### Section 2: Budget & Dreams
- Total budget & budget status
- Splurge preferences
- Color themes and inspiration links
- Photo uploads

### Section 3: Priorities
- Select top priorities (decor, food, photography, etc.)
- Non-negotiable must-haves
- Things to avoid
- Important deadlines

### Section 4: Services Checklist
- Browse services by category
- 90+ items to choose from
- Each item has description and tag (Essential/Optional)
- Real-time progress tracking

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS Variables, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- html2pdf.js - PDF generation
- EmailJS - Email delivery service
- Google Fonts (Inter, Cormorant Garamond)
